# BMTB FiveM DLSS 5 Installer

### One-click DLSS installation for FiveM

**BMTB FiveM DLSS 5 Installer** is a free Windows utility designed to make installing the correct DLSS package for FiveM simple.

No manual DLL copying.  
No complicated folder setup.  
No account required.

The installer detects your FiveM installation, checks your NVIDIA RTX GPU, selects the correct package, creates a backup, and installs the required files automatically.

# Supported GPU Packages

The installer currently includes two package groups.

### RTX 20 / 30 / 40 Series

Designed for supported NVIDIA GeForce RTX:

- RTX 20 Series
- RTX 30 Series
- RTX 40 Series

### RTX 50 Series

Designed for supported NVIDIA GeForce RTX:

- RTX 50 Series

The installer attempts to detect your graphics card automatically and select the correct package.

You can also manually change the selected package before installation.
