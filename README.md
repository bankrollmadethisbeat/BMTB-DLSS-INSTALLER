# 📖 About

**BMTB FiveM DLSS 5 Installer** is a free Windows utility designed to make installing the correct DLSS package for FiveM as simple as possible.

No manually copying DLL files.

No digging through FiveM folders.

No guessing which GPU package you need.

The installer is designed to automatically:

- 🔍 Detect your FiveM installation
- 🎮 Detect your NVIDIA RTX GPU
- 📦 Select the recommended DLSS package
- 💾 Back up supported existing files
- ⚡ Install the required DLSS files
- 🛠️ Repair damaged or missing files
- ♻️ Restore your previous files
- 🔐 Verify installed file integrity
- 🩺 Run installation diagnostics
- 🔄 Check GitHub for newer BMTB releases

The normal installation experience is designed to be:

```text
Open Installer
      ↓
Detect FiveM
      ↓
Detect GPU
      ↓
Click INSTALL DLSS 5
      ↓
Done
```

# 💾 Automatic Backup

Before replacing supported existing files, BMTB creates a backup.

This helps make returning to your previous setup much easier.

BMTB may back up files such as:

```text
dxgi.dll
ReShade.ini
ReShadePreset.ini
nvngx_dlss.dll
```

and other installer-managed files that already existed.

> [!IMPORTANT]
> BMTB does **not** intentionally delete your entire `plugins` folder.

The installer only manages files controlled by the BMTB DLSS installation.

---

# 🛡️ Unrelated File Protection

BMTB is designed to preserve unrelated FiveM content.

Examples of files that should remain untouched include:

```text
FiveM.app\plugins\my_custom_plugin.dll
```

and unrelated ReShade shader files such as:

```text
FiveM.app\plugins\reshade-shaders\Shaders\MyCustomShader.fx
```

The installer should not wipe unrelated plugins just because DLSS is being installed.

---

# ♻️ Restore Previous Files

Want to return to the setup you had before BMTB DLSS was installed?

Use:

```text
Restore Previous Files
```

The restore system is designed to:

- ✅ Restore files that existed before BMTB installation
- ✅ Remove BMTB files that did not previously exist
- ✅ Preserve unrelated FiveM plugins
- ✅ Preserve unrelated ReShade shaders
- ✅ Restore the original pre-install state where possible

# 🛠️ Repair Installation

the installer may offer:


Repair restores BMTB-managed files while preserving unrelated content.
